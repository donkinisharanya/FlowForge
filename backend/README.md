# FlowForge


Production-style backend platform for task management and team collaboration.

## Stack
- Node.js
- TypeScript
- Express
- PostgreSQL
- Prisma
- Redis
- JWT
- bcrypt
- Zod
- Docker
- Vitest
- Supertest
- Swagger

## Features
- User registration and login
- JWT authentication
- Organizations and members
- Projects CRUD
- Tasks CRUD
- Task comments
- Authorization
- Input validation
- Pagination and project search
- Redis caching and invalidation
- Rate limiting
- Security headers
- Security headers
- Health checks
- Swagger API documentation
- Automated API tests

## Development
npm install
npx prisma generate
npm run dev
